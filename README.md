# 護眼貓 🐱 (eye_rest)

一隻住在 Mac 選單列的貓,依照護眼研究,在你用電腦太久時提醒你休息。
A cat that lives in your Mac menu bar and reminds you to rest your eyes, based on eye-health research.

---

## 這是什麼

常駐選單列的護眼提醒,用三層休息週期照顧你的眼睛和身體:

| 層級 | 預設間隔 | 休息時間 | 目的 |
|------|----------|----------|------|
| 👀 看遠方喵 | 每 20 分 | 20 秒 | 20-20-20 法則,放鬆睫狀肌 |
| 🐾 伸懶腰喵 | 每 50 分 | 3 分 | 起身活動,肌肉骨骼 + 認知重置 |
| 😴 打個盹喵 | 每 120 分 | 5 分 | 離開螢幕,整體疲勞修復 |

休息時間到 → 全螢幕柔色貓咪畫面 + 倒數;結束時喵一聲提醒你回來,並自動切回原本的視窗。

## 安裝(macOS)

1. 下載這個專案(綠色「Code」→「Download ZIP」),解壓縮
2. **雙擊 `install.command`** — 它會自動裝好需要的套件並啟動
3. 看 Mac 右上角選單列的 🐱 圖示

> 第一次雙擊若出現「來自未識別的開發者」警告:
> **右鍵點檔案 → 打開 → 再按一次「打開」** 即可。
>
> 看不到圖示(瀏海機種)?按住 ⌘ Command 鍵,把選單列上任一小圖示往下拖掉空出位置。

需求:macOS、Python 3(內含 tkinter)。`install.command` 會自動處理 `rumps` 套件;
若你沒有含 tkinter 的 Python,它會引導你到 [python.org](https://www.python.org/downloads/macos/) 安裝。

## 使用

點選單列的 🐱:

- 看三層各自的倒數
- 讓貓打盹(暫停)/ 跳過下一個
- 設定間隔(每層可調)
- 看家時段(只在指定時段提醒,開始/結束時間可調)
- 允許偷偷略過(關掉就強制休息)
- 結束時喵一聲(開/關)
- 開機自動啟動(開/關)
- 叫貓咪現在出來(立即測試)

以後啟動:雙擊 `start.command`。

## 更新到最新版

雙擊 **`update.command`**:

- 用 `git clone` 下載的 → 自動拉最新版並重啟
- 用 ZIP 下載的 → 自動打開下載頁面,重新下載 ZIP 蓋回原資料夾(同一位置)即可

你的設定不會遺失(存在 `~/.eye_rest_config.json`,與程式檔分開)。

## 換成自己的貓叫聲

把任意音效檔命名為 `meow.mp3` 放進資料夾即可(蓋過預設的)。
沒有 `meow.mp3` 時,程式會自動合成一個內建的「喵~」音(`meow.wav`)。

## 設定檔

存在 `~/.eye_rest_config.json`,改選單即會寫入,每台電腦各自獨立。

## 檔案說明

| 檔案 | 作用 |
|------|------|
| `eye_rest.py` | 選單列主程式,三層計時器 |
| `break_overlay.py` | 全螢幕休息畫面 |
| `install.command` | 一鍵安裝(裝套件 + 啟動) |
| `start.command` | 之後的日常啟動 |
| `update.command` | 一鍵更新到最新版 |
| `meow.mp3` | 休息結束的貓叫聲(可自行替換) |
